关于

记录普通但温暖的日常

这里是我的生活记录网页，用来保存一些和朋友出去玩、旅行、聚会、校园生活以及日常碎片的照片和文字。很多瞬间可能很普通，但过一段时间再回头看，都会变成很珍贵的回忆。

每一张照片背后都有一个故事，每一次翻看都是一次小小的时光机器。希望这个小站可以成为我和朋友之间的温柔记忆库。
