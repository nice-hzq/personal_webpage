# 个人生活记录网页

这是一个基于 HTML / CSS / JavaScript 的个人生活记录网页模板，适合用来展示照片、旅行回忆、朋友瞬间和心情留言。页面风格温暖、简洁、适合在浏览器直接打开使用。

## 项目结构

```
life-website/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── images/
        ├── cover.jpg
        ├── avatar.jpg
        ├── trip-01.jpg
        ├── trip-02.jpg
        ├── trip-03.jpg
        ├── trip-04.jpg
        ├── trip-05.jpg
        └── trip-06.jpg
```

## 如何运行

1. 将整个 `life-website` 文件夹保存在本地。
2. 用浏览器打开 `index.html`。
3. 页面会直接加载，不需要任何后端服务器。

## 如何替换照片

1. 找到 `assets/images/` 文件夹。
2. 用你自己的照片替换默认图片，例如 `cover.jpg`、`avatar.jpg`、`trip-01.jpg` 等。
3. 如果你没有某张图片，网页会自动显示一个友好的占位图，不会导致页面崩溃。

## 如何新增照片卡片

1. 打开 `assets/js/main.js`。
2. 在 `photos` 数组中添加一个新的对象，格式如下：

```javascript
{
  src: "assets/images/trip-07.jpg",
  title: "新的照片标题",
  date: "2026-05-09",
  desc: "这里写这张照片背后的故事。",
  category: "旅行",
  tag: "旅行 / 朋友"
}
```

3. 将对应图片放在 `assets/images/` 中。
4. 保存后刷新页面即可看到新增照片。

## 如何修改网页标题和文字

- `index.html` 中可以修改页面标题、导航文字、首页标语、关于区域文字、页脚内容等。
- `assets/js/main.js` 中可以修改照片数据、时间线数据、瞬间卡片、留言功能等。

## 主要功能

- 顶部导航支持平滑滚动
- 首页封面区域带有遮罩和按钮
- 相册区支持分类筛选
- 点击图片可弹出大图预览
- 时间线记录生活片段
- 朋友瞬间卡片展示
- 留言区支持本地保存和删除
- 响应式布局适配电脑、平板、手机

## 其他提示

- 如果你打算公开网页内容，请先检查照片和文字是否适合分享。
- 你可以在 `style.css` 中调整颜色、圆角、间距等视觉细节。
- 未来可以继续添加夜间模式、更多分类、地点字段或照片排序功能。
